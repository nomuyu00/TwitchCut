# 横動画のサムネイル

Topicsの各動画とDigestに1枚ずつ作る。Shortsのカスタムサムネイルは不要。制作前に動画の前提、主役、見どころ、オチを確認する。

1. 該当動画の実配信画面から背景候補を選ぶ。原本パス、source時刻、採用理由を保存する。ぼかしが必要な外部画面や個人情報は、静止画にも反映する。
2. 小さく表示しても何の動画か伝わる短い見出しと、主役へ目線が向かう配置を設計する。実際にない発言や出来事を見出しで捏造しない。
3. Canvaの通常編集で制作する。利用者がこの用途の静止画送信を依頼・承認済みなら繰り返し確認せず進める。未承認なら、送る画像とサムネイル制作の用途を明示した確認が必要。動画・音声のアップロードや画像生成を含めない。
4. 原寸と一覧サイズの縮小表示を実見する。文字の可読性、主役の視認性、実配信背景が残っていること、個人情報の露出を確認する。Canva編集URLと最終PNG/JPEGを保存し、最終画像のSHAをQAへ記録する。

単色背景、画像生成、動画に関係しない汎用画像、毎回同じ「文字が左・絵が右」の二分割を使わない。色と文言だけ変えた量産構図にしない。暗くしたり軽くぼかす場合も、元の配信場面が分かる程度に残す。

利用者提供のアバター・反応素材は実見し、表情と内容が合う場合だけ使う。アバターを必ず入れたり、全動画の同じ角に同じ大きさで置いたりしない。絵・ゲーム画面・制作画面だけで伝わる構図も採用する。反応素材で背景を全面的に隠さない。

Canvaへ接続できない場合は、ローカルの背景候補、文言、配置案、ぼかし済み静止画まで準備し、Canva制作・最終確認が未完了であると示す。Canvaで編集していないファイルをCanva完成品として記録しない。別手段を利用者が明示指定したときはその指示を優先する。

投稿時の画像サイズ・容量条件は[YouTube公式のサムネイル説明](https://support.google.com/youtube/answer/72431?hl=ja)と実際の投稿欄で確認する。推奨寸法が変わっただけで既存の受理済み画像を失敗扱いせず、画質、可読性、実際の受理を調べる。
